빅데이터 분석기사 실기 준비를 위한 파이썬 라이브러리 학습 기록 repository

</br>

### 학습 자료

- 데이터마님 > 파이썬 기초 > 라이브러리 학습

[🔗데이터마님 라이브러리 학습](https://www.datamanim.com/learn/python-basics/libraries)   

</br>

### 학습 목적

- 빅데이터 분석기사 실기 대비
- 데이터 전처리 문제 풀이 기록
- 자주 틀리는 문제 유형 정리
- 사용자 풀이 코드와 정답 코드 비교

</br>


### 라이브러리별 역할
- pandas 기초: CSV 파일 읽기, 열 선택, 조건 필터링, 정렬, 집계
- sklearn 기초: 데이터 분리, 스케일링, 회귀/분류 모델 학습, 예측
- statsmodels 기초: 회귀모형 적합, 계수 해석, p값 확인
- scipy 기초: 정규성검정, t검정, 카이제곱검정 같은 통계 검정
